# Mortify Website Starter

Static website build for mortify.co.uk.

## Upload to Plesk
1. Extract the ZIP.
2. Upload `index.html` and the `assets` folder into the site's document root, usually `httpdocs`.
3. If replacing WordPress, back up the existing site first.
4. If keeping WordPress, use this as a design/content reference or convert the HTML into a theme/template.

## Contact form
The form currently uses `mailto:hello@mortify.co.uk`. Replace this with a proper form handler or WordPress form plugin when deployed.
