# Mortify Website Starter

Static website build for mortify.co.uk.

## Upload
Static HTML, not WordPress. Upload the document root as-is: `index.html`, `assets/`, `services/`, `ai-assistants/`, `pricing/`, `work/`, `support/`, `contact/`, `privacy/`, `blog/`, `robots.txt`, `sitemap.xml` and `CNAME`.

Do not upload over a live site until the prices on `/ai-assistants/` and `/pricing/` are confirmed. Those figures are draft starting prices.

## Contact form
The form currently uses `mailto:hello@mortify.co.uk`. Replace this with a proper form handler or WordPress form plugin when deployed.
